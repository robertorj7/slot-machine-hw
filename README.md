# HERO MACHINE - Slot Machine

Este projeto é uma máquina caça-níquel (slot machine) temática de heróis, desenvolvida para fins de aprendizado e entretenimento.

## Objetivo
  Ao clicar no botão `SPIN` os slots devem ser embaralhados. Após serem embaralhados, caso os 3 slots tenham o mesmo valor
  é necessário alterar o titulo "HERO MACHINE" com uma mensagem temporária, além de atualizar o "dinheiro" do jogador. Caso o dinheiro zere, ou fique negativo, não será mais possível jogar.

## Funcionalidades

- Interface gráfica simples e responsiva.
- Três slots com imagens de heróis.
- Botão "Spin" para girar os slots.
- Exibição do saldo do jogador.
- Animações e feedback visual ao girar.

## Tecnologias usadas:
